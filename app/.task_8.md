### 4. src/app/api/songs/route.ts
- GET: Return latest 50 songs for authenticated user, ordered by created_at desc. Include all fields.

### 5. src/app/api/songs/[id]/route.ts
- GET: Return single song. If user owns it, return full row. If song is_public, return it without auth. Otherwise 404.
- PATCH: Update song. Body: `{ is_public?, title? }`. Verify ownership.
- DELETE: Delete song. Verify ownership. Also delete from Supabase Storage (audio and covers buckets). Delete DB row.

### 6. src/app/api/songs/[id]/play/route.ts
- POST: Record play event. Insert into play_history table. Increment songs.play_count. Set songs.status to 'played' if it was 'queued'.

### 7. src/app/api/songs/[id]/rate/route.ts
- POST: Submit rating. Body: `{ rating: number }` (0-10 integer).
- Upsert into song_ratings (insert or update if exists for same song_id).
- Update songs.rating with the value.
- If rating >= 8: set songs.resurface = true
- If rating <= 4: set songs.resurface = false
- Return: `{ ok: true, resurface: boolean }`
