# AGENT 5 TASK — Dashboard + Generate Page UI

You are Agent 5 for the myTrack project. PLAN your approach first, then build. Read this ENTIRE task.

## YOUR JOB
Build the Dashboard page and the Generate page with all 3 states (concept picker, generating progress, player + rating). Also create reusable components.

## PROJECT CONTEXT
- Next.js 14 App Router, TypeScript, 'use client' for interactive pages
- Types at: src/lib/types.ts (Song, SoundProfile, Concept, GenerationStep, AudioFeatures)
- No Tailwind, no CSS modules — INLINE STYLE OBJECTS ONLY
- Font: IBM Plex Sans (already loaded globally via next/font)
- Color vars: var(--bg) #F7F6F2, var(--ink) #111111, var(--ink-muted) #555555, var(--border) #D0CEC8, var(--accent) #111111, var(--accent-inverse) #F7F6F2, var(--card-bg) #FFFFFF, var(--progress) #111111
- NO ROUNDED CORNERS on any structural element (cards, buttons, inputs, panels)
- 1px solid var(--border) for grid separators
- Minimum 16px padding on all panels
- Bar charts: pure inline SVG, NO chart library
- Audio scrubber: div-based, NOT native input type="range"
- Rating slider: div-based, NOT native input type="range"
- Clerk: import { UserButton } from '@clerk/nextjs' for the user avatar button
- All API calls use fetch() to the /api/* routes

### 2. src/app/generate/page.tsx ('use client')

Three sequential states managed by React state:

**State 1 — Concept Picker:**
- Optional mood hint: text input with placeholder "late night drive, studying, hype workout..." 
- Input style: 1px border var(--border), no rounded corners, padding 12px, full width
- [Regenerate] button next to input
- 3 concept cards in a row, each showing: title (bold), genre + BPM, mood, structure_hint, why text
- Card style: 1px border var(--border), no rounded corners, padding 16px
- [Select] button on each card: background var(--accent), color var(--accent-inverse)
- On mount: POST /api/generate/ideas with sound_profile and mood_hint

**State 2 — Generating:**
- Progress checklist showing each step
- Steps: "Reading your Sound Profile..." -> "Direction selected" -> "Engineering your track..." -> "Composing with Lyria..." -> "Generating cover art..." -> "Saving your song..." -> "Your song is ready"
- Each completed step: checkmark icon (plain text checkmark character)
- Current step: spinning indicator (CSS animation, inline keyframes via style tag)
- Progress bar for Lyria step: div-based, var(--progress) fill
- Fire API calls in sequence: POST /api/generate/prompt, then POST /api/generate/music and POST /api/generate/cover in parallel, then POST /api/generate/embed in background

**State 3 — Player + Rating:**
- Cover art image (200x200), title, genre + BPM, duration
- Custom audio player (see AudioPlayer component below)
- Action buttons: [+ Playlist] [Share]
- Rating slider appears after 20s of playback or when song ends
- Rating: div-based slider 0-10, integer steps, default position 5
- [Submit] button and [Skip rating] link
- Below player: "UP NEXT" section showing 3 queue cards
- Queue cards: cover thumbnail + title, or "generating..." placeholder with animated dots
- [Skip] button to play next queued song
- On mount of State 3: fire POST /api/generate/queue in background

### 3. src/components/AudioPlayer.tsx ('use client')

Custom audio player using HTML5 Audio API + div-based UI:
- Play/Pause button (toggle)
- Custom scrubber: outer div (track, 1px height, var(--border) background), inner div (progress, var(--progress) fill)
- Click on track to seek
- Time display: current / total in M:SS format  
- Volume control (optional, simple)
- All styling via inline style objects
- Props: { src: string, onEnded?: () => void, onTimeUpdate?: (currentTime: number) => void }

## IMPORTANT CONSTRAINTS
- ALL styling via inline style objects — no CSS classes, no CSS modules, no Tailwind
- NO rounded corners (borderRadius: 0 or just don't set it)
- Use var() CSS custom properties via string values in style objects, e.g.: { color: 'var(--ink)' }
- Font is already set globally — don't re-import it
- Make it responsive: use CSS grid or flexbox via inline styles with media query workaround (check window.innerWidth in useEffect for responsive breakpoints)
