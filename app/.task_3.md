### 5. src/app/api/generate/queue/route.ts (POST)

Pre-generates 3 songs for the queue. Fires in background after first song loads.

Steps:
1. Fetch user's Sound Profile from DB
2. Generate 9 concepts via Flash (one call returning 9) then pick best 3 by diversity (different genres)
3. Check if user has any songs with resurface=true. If so, replace 1 of the 3 queue slots with a fresh regeneration of the highest-rated resurfaceable song's concept. Max 1 resurfaced slot.
4. For each of 3 concepts: call the prompt, music, and cover generation in parallel (using internal function calls, not HTTP)
5. Store each with status='queued', queue_position=1|2|3
6. Return: `{ queued: 3 }`

Set `export const maxDuration = 120;` for this route too.
