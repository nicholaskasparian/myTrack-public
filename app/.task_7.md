## API ROUTES TO CREATE

### 1. src/app/api/playlists/route.ts
- GET: Return all playlists for authenticated user. Include song count and first 4 cover_urls for mosaic. Query:
  ```
  Select playlists.*, count(playlist_songs.id) as song_count from playlists left join playlist_songs...
  ```
  Actually, use two queries: get playlists, then for each get top 4 song cover_urls via playlist_songs join songs.
- POST: Create playlist. Body: `{ name: string, is_public: boolean }`. Insert with nanoid(10) as id.

### 2. src/app/api/playlists/[id]/route.ts
- PATCH: Update playlist name or is_public. Body: `{ name?, is_public? }`. Verify ownership.
- DELETE: Delete playlist. Verify ownership. Cascade deletes playlist_songs.

### 3. src/app/api/playlists/[id]/songs/route.ts
- GET: Return ordered songs for playlist. Join playlist_songs with songs table, order by position. If playlist is_public, allow without auth. Otherwise require auth + ownership.
- POST: Add song to playlist. Body: `{ song_id: string }`. Set position = max(position) + 1. Insert with nanoid(10).
- PATCH: Reorder songs. Body: `{ ordered_song_ids: string[] }`. Update position for each to match array index.

### 4. src/app/api/playlists/[id]/songs/[songId]/route.ts
- DELETE: Remove song from playlist. Verify playlist ownership.
