# AGENT 2 TASK — Spotify OAuth + Sound Profile Algorithm

You are Agent 2 for the myTrack project. PLAN your approach first, then build. Read this ENTIRE task carefully.

## YOUR JOB
Implement the Spotify sync endpoint that pulls the user's Spotify listening data via Clerk OAuth tokens and computes a Sound Profile (a quantitative fingerprint of musical taste).

## PROJECT CONTEXT
- Next.js 14 App Router project, TypeScript
- Auth: Clerk (@clerk/nextjs v5)
- DB: Supabase (@supabase/supabase-js v2)
- Supabase has these tables already created: sound_profiles, songs, play_history, song_ratings
- IDs are generated app-side using nanoid (import { nanoid } from 'nanoid')
- Server utilities exist at: src/lib/supabase.ts (exports getSupabaseAdmin) and src/lib/types.ts (exports SoundProfile, AudioFeatures, Song)

## FILE TO CREATE
**src/app/api/spotify/sync/route.ts** — POST handler

## IMPLEMENTATION SPEC

### Step 1: Auth
```typescript
import { auth, clerkClient } from '@clerk/nextjs/server';
```
- Call auth() to get userId. If no userId, return 401.
- Fetch Spotify token: `const tokenResponse = await clerkClient().users.getUserOauthAccessToken(userId, 'oauth_spotify');`
- Extract `const spotifyToken = tokenResponse.data[0]?.token;`
- If no token, return `{ error: 'spotify_not_connected' }` with status 400.

### Step 2: Fetch Spotify Data (all in parallel with Promise.all)
Use fetch() with Authorization: `Bearer ${spotifyToken}` header.

Endpoints to call:
1. `https://api.spotify.com/v1/me/top/tracks?time_range=short_term&limit=50`
2. `https://api.spotify.com/v1/me/top/tracks?time_range=medium_term&limit=50`
3. `https://api.spotify.com/v1/me/top/tracks?time_range=long_term&limit=50`
4. `https://api.spotify.com/v1/me/top/artists?time_range=medium_term&limit=50`
5. `https://api.spotify.com/v1/me/player/recently-played?limit=50`

Handle Spotify 429 errors: read Retry-After header, wait that many seconds (cap at 10s), retry once. If still 429, continue with whatever data was fetched.

### Step 3: Fetch Audio Features
Collect all unique track IDs from the 3 top-tracks responses. Batch them into groups of up to 100.
Call: `https://api.spotify.com/v1/audio-features?ids=${batch.join(',')}`

### Step 4: Compute Sound Profile

For each audio feature dimension (tempo, energy, valence, danceability, acousticness, instrumentalness, speechiness, liveness):
```
short_avg = average of that feature across short-term tracks
medium_avg = average of that feature across medium-term tracks  
long_avg = average of that feature across long-term tracks
weighted_avg = (short_avg * 0.5) + (medium_avg * 0.35) + (long_avg * 0.15)
```

**Genre extraction:**
- Flatten all artists' `genres` arrays from the top artists response
- Count frequency of each genre
- Take top 5 by count

**Time-of-day pattern** (from recently-played):
- Parse `played_at` timestamps
- Bin into: Morning (6-12), Afternoon (12-18), Evening (18-24), Night (0-6)
- Output: the window with most plays (e.g., "evening")

**Top artists:** Take the first 10 artist names from the top artists response.

**In-platform modifiers:** Also fetch from Supabase:
- play_history rows for this user (get song_ids)
- song_ratings rows for this user
- For each played myTrack song, look up its concept_json and extract feature values
- Play count modifier: add 0.1 * (song feature values) to the weighted averages. Cap total myTrack influence at 20% of final weight.
- Rating modifier: ratings 8-10 = multiply that song's contribution by 1.5. Ratings 0-4 = subtract 0.05 * feature values. Ratings 5-7 = neutral (normal play weight).
- Set `resurface = true` on songs rated 8+, `resurface = false` on songs rated 0-4.

### Step 5: Store Profile
Upsert into sound_profiles table using getSupabaseAdmin():
```typescript
const supabase = getSupabaseAdmin();
await supabase.from('sound_profiles').upsert({
  id: nanoid(10),
  user_id: userId,
  synced_at: new Date().toISOString(),
  features: computedFeatures,
  top_genres: topGenres,
  top_artists: topArtists,
  dominant_listening_window: dominantWindow,
  spotify_track_count: allTrackIds.length,
  aura_play_count: playHistory.length,
  aura_avg_rating: avgRating,
}, { onConflict: 'user_id' });
```

### Step 6: Return
Return `NextResponse.json({ profile })` with the computed Sound Profile.
